# TokenCalc - AI Token Calculator

A free, browser-based token counter and API cost estimator for 90+ AI models including GPT-5, Claude, Gemini, DeepSeek, and more.

## Features

- **Exact token counts** for OpenAI models using tiktoken
- **Cost estimation** for 90+ LLM models
- **100% private** - runs locally in your browser
- **No upload required** - your data never leaves your device

## Models Supported

- OpenAI: GPT-5, GPT-4o, o1, o3, GPT-4.1, GPT-4, GPT-3.5
- Anthropic: Claude 4 Opus, Sonnet, Haiku
- Google: Gemini 2.5 Pro, Flash
- DeepSeek: V3, R1
- Meta: Llama 3, Llama 4
- Qwen, Mistral, xAI Grok, and more
