What tokenizer does GPT-5 use?

GPT-5, GPT-5 mini, GPT-5.5 and GPT-4o all use the o200k_base tokenizer — the same Byte-Pair Encoding (BPE) implementation that OpenAI runs on their servers. This is different from the older cl100k_base tokenizer used by GPT-4 and GPT-3.5, which is why your token count can change when you switch between them.

The o200k_base vocabulary has roughly 200,000 subword units, which means common English words are more likely to be single tokens than with older tokenizers. In practice, this gives you a slightly lower token count for the same text compared to GPT-4.

Why token counts differ between GPT-5 and GPT-4

Even though GPT-5 and GPT-4 are both OpenAI models, they use different tokenizers. GPT-4 uses cl100k_base (roughly 100K vocabulary), while GPT-5 uses o200k_base (roughly 200K). This means the same text can tokenize differently:

  • Common English words like "the", "and", "is" tokenize the same way in both.
  • Rare words and technical terms may be single tokens in o200k_base but split in cl100k_base.
  • Code and symbols benefit most from the larger vocabulary.

Frequently asked questions

How many tokens is a word in GPT-5?

On average, 1 token ≈ 0.75 words in GPT-5, or roughly 4 characters per token. However, this varies by text type — code tokenizes more efficiently, while repeated punctuation can inflate token counts.

What tokenizer does GPT-5 use?

GPT-5 uses o200k_base, the same tokenizer as GPT-4o. This is a 200K-word vocabulary Byte-Pair Encoding tokenizer, which is larger than the cl100k_base tokenizer used by GPT-4 and GPT-3.5.

How much does GPT-5 cost per 1M tokens?

GPT-5 costs $1.25 per 1M input tokens and $10.00 per 1M output tokens, with a 400K context window. GPT-5 mini is significantly cheaper at $0.25 / $2.00 per 1M tokens.
