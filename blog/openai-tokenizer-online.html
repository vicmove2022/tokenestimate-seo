What is a Tokenizer?

A tokenizer converts text into tokens - the basic units that AI models process. Understanding tokenization helps you estimate costs and avoid context limit errors.

How Tokenization Works

OpenAI uses Byte-Pair Encoding (BPE) to tokenize text:

  • Common words become single tokens
  • Uncommon words split into subwords
  • Special characters handled separately

Example Tokenization

"Hello world!" 
→ ["Hello", " world", "!"] 
→ 3 tokens

"This is a test"
→ ["This", " is", " a", " test"]
→ 4 tokens

Why Token Count Matters

  1. Cost estimation: Know your API costs upfront
  2. Context limits: Stay within model limits
  3. Prompt optimization: Write more efficiently
