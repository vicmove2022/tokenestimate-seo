Infrastructure Costs

  • Hosting: $50-500/month (Vercel, Railway, AWS)
  • Database: $20-200/month (Supabase, PostgreSQL)
  • Vector DB: $50-500/month (Pinecone, Weaviate)
  • CDN: $10-100/month (Cloudflare)
  • Monitoring: $50-300/month (Sentry, Umami)

Total Cost Examples

MVP (Simple Chatbot)

  • Development: $15,000
  • Monthly API: $200
  • Infrastructure: $100
  • Total Year 1: ~$18,000

Production (RAG Chatbot)

  • Development: $60,000
  • Monthly API: $2,000
  • Infrastructure: $500
  • Total Year 1: ~$90,000

Cost Optimization Tips

  1. Start with GPT-4o mini for MVP
  2. Implement caching for repeated queries
  3. Use streaming to improve UX
  4. Monitor usage daily
  5. Consider hybrid: local + cloud
