First API Call Example

import openai

client = openai.OpenAI(api_key="sk-...")

response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in 3 sentences."}
  ]
)

print(response.choices[0].message.content)
print(f"Tokens used: {response.usage}")

Streaming Responses

response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role": "user", "content": "Tell me a story"}],
  stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

Error Handling

try:
    response = client.chat.completions.create(...)
except openai.RateLimitError:
    # Wait and retry
    time.sleep(60)
except openai.BadRequestError as e:
    # Invalid input
    print(f"Error: {e}")
except openai.APIError as e:
    # Other API errors
    print(f"API Error: {e}")

Cost Optimization Tips

  1. Use GPT-4o mini for simple tasks (4x cheaper)
  2. Implement prompt caching for repeated inputs
  3. Set max_tokens to control output length
  4. Use streaming to reduce perceived latency
  5. Cache responses for identical queries
