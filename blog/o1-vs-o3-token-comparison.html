The Rise of Reasoning Models

OpenAI's o1 and o3 are the first models to heavily use reasoning tokens — hidden computational steps that let the model think before responding. But reasoning tokens count toward your bill, often at higher rates.

Hidden Reasoning Token Costs

When you use o1 or o3, the model generates reasoning tokens before producing the final output. These tokens are:

  • Not visible in the API response
  • Charged at the same rate as output tokens
  • Can be 2-5x longer than the visible response

Cost Calculation Example

For a complex math problem:

  • Input: 500 tokens ($7.50 with o1)
  • Visible output: 200 tokens ($12.00)
  • Hidden reasoning: ~800 tokens ($48.00)
  • Total: $67.50 (not $19.50!)

When to Use Each Model

  • o1: Complex math, code generation, scientific reasoning
  • o3: Balanced tasks, better cost-efficiency, faster responses

FAQ

Are reasoning tokens charged differently?

No, reasoning tokens are charged at the same rate as output tokens for o1 and o3.

Can I see reasoning tokens in the API response?

No, reasoning tokens are internal and not returned in the standard API response.
