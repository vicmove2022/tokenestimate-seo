OpenAI Tokenizer Explained

Deep dive into how OpenAI's tokenizer converts text into tokens using Byte-Pair Encoding (BPE).

Aug 16, 2026 · 12 min read

What is Tokenization?

Tokenization is the process of converting text into smaller units called tokens. AI models read and generate text in tokens, not words or characters.

Byte-Pair Encoding (BPE)

OpenAI uses BPE, a subword tokenization algorithm that:

  • Starts with individual characters
  • Merges most frequent character pairs
  • Creates a vocabulary of common subwords

Why Token Counts Matter

  • API pricing is per-token
  • Context windows limit input length
  • Different models tokenize differently

Code Example

import tiktoken

enc = tiktoken.get_encoding("o200k_base")
tokens = enc.encode("Hello, world!")
print(f"Tokens: {len(tokens)}")
print(f"Decoded: {enc.decode(tokens)}")
