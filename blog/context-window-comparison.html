What is a Context Window?

The context window is the maximum amount of text (in tokens) that an AI model can process in a single request.

Choosing the Right Context

  • Short conversations: Any model works
  • Document analysis: Need 100K+ context
  • Long-form content: Consider Gemini or Claude
  • Budget projects: DeepSeek offers great value

Cost per Token

Don't just look at context size — calculate cost per token:

Effective cost = (Input price × tokens used) / context window
Gemini Flash: $0.075/1M tokens (best value)
