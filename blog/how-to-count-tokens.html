How to Count Tokens

Complete guide with Python code examples for counting tokens in your text.

Aug 16, 2026 · 8 min read

Why Count Tokens?

Understanding token count helps you:

  • Estimate API costs before making requests
  • Stay within context window limits
  • Optimize prompts for efficiency

Method 1: Using Tiktoken (Recommended)

import tiktoken

def count_tokens(text, model="gpt-4o"):
    encoding = tiktoken.encoding_for_model(model)
    tokens = encoding.encode(text)
    return len(tokens)

# Example
text = "Hello, how are you?"
token_count = count_tokens(text)
print(f"Tokens: {token_count}")

Method 2: Using OpenAI API

from openai import OpenAI

client = OpenAI()

response = client.embeddings.create(
    model="text-embedding-3-small",
    input=["Your text here"]
)
# Note: This counts embedding tokens, not chat tokens

Method 3: Rough Estimate

# English: 1 token ≈ 0.75 words
estimated_tokens = int(len(text.split()) / 0.75)

# Or simpler:
estimated_tokens = int(len(text) / 4)
