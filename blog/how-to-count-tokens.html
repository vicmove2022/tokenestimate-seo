Common Mistakes to Avoid

  1. Using character counters — Tokens ≠ characters
  2. Ignoring system prompts — They add tokens too
  3. Forgetting output tokens — Both input and output are billed
  4. Not accounting for reasoning tokens — o1/o3 have hidden costs

Cost Optimization Tips

  • Use smaller models for simple tasks (GPT-4o mini, Claude Haiku)
