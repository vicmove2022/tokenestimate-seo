AI Token Calculator API — Count Tokens Programmatically

Integrate token counting into your applications with these code examples and API guides.

Aug 16, 2026 · 9 min read

Why Programmatic Token Counting?

When building AI applications, you need to estimate costs before making API calls. Programmatic token counting helps you:

  • Predict API costs accurately
  • Implement rate limiting
  • Optimize prompt length
  • Build cost monitoring dashboards

Python Implementation

import tiktoken

def count_tokens(text, model="gpt-4o"):
    enc = tiktoken.encoding_for_model(model)
    return len(enc.encode(text))

# Usage
tokens = count_tokens("Hello, world!")
print(f"Tokens: {tokens}")

JavaScript Implementation

const { getEncoding } = require('tiktoken');

function countTokens(text, model = 'gpt-4o') {
  const enc = getEncoding('o200k_base');
  const tokens = enc.encode(text);
  enc.free();
  return tokens.length;
}
