Word → Token Conversion Formulas

  • Chinese: tokens = characters × 1.5

FAQ

How many tokens is 1000 words?

About 1300 tokens for English text. Code may have fewer tokens (~1100).

Do all models use the same tokenizer?

No. Each provider uses a different tokenizer. Our calculator shows exact counts for OpenAI and estimates for others.
