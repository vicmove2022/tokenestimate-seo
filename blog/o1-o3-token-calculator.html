What Are Reasoning Tokens?

o1 and o3 models use "reasoning tokens" — additional tokens consumed during the model's thinking process before generating the final response.

Important: Hidden Costs

Reasoning tokens can be 5-50x the output tokens! Always account for them in your cost estimates.

Example Cost Calculation

// o1 model request
Input: 1,000 tokens × $15.00 = $0.015
Output: 500 tokens × $60.00 = $0.030
Reasoning: 5,000 tokens × $60.00 = $0.300
Total: $0.345 (not $0.045!)

Cost-Saving Tips

  • Use o1 mini or o3 mini when possible
  • Set max_tokens limits
  • Use streaming to see reasoning costs in real-time
