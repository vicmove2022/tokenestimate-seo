What is a GPT Token?

A token is the basic unit of text that GPT models process. One token can be a word, part of a word, or even a single character.

Supported GPT Models

  • GPT-5, GPT-5 mini, GPT-5.5
  • GPT-4o, GPT-4o mini
  • o1, o1 mini, o3, o3 mini
  • GPT-4, GPT-4 Turbo
  • GPT-3.5 Turbo

How to Count GPT Tokens

import tiktoken

# For GPT-4o, GPT-5, o-series
enc = tiktoken.get_encoding("o200k_base")
tokens = enc.encode("Your text here")
print(f"Tokens: {len(tokens)}")
