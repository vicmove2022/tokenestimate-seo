API Rate Limits Explained

Understand rate limits and learn strategies to avoid 429 errors in your AI applications.

Aug 16, 2026 · 8 min read

What are Rate Limits?

Rate limits control how many requests you can make in a given time period. They prevent abuse and ensure fair usage across all users.

Key Metrics

MetricMeaningExample
RPMRequests Per Minute1000 RPM = 1000 requests/min
TPMTokens Per Minute10M TPM = 10M tokens/min
RPDRequests Per Day1M RPD = 1M requests/day

Strategies to Avoid Rate Limits

  1. Implement queuing: Buffer requests and process in batches
  2. Add delays: Space out requests with sleep intervals
  3. Use exponential backoff: Wait longer after each failed attempt
  4. Monitor usage: Track your rate limit consumption
  5. Upgrade tier: Get higher limits with paid plans

Python Implementation

import time
from openai import AsyncOpenAI
import asyncio

async def rate_limited_call(client, prompt):
    max_retries = 3
    for i in range(max_retries):
        try:
            response = await client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{"role": "user", "content": prompt}]
            )
            return response
        except RateLimitError:
            wait_time = 2 ** i
            print(f"Rate limited. Waiting {wait_time}s...")
            await asyncio.sleep(wait_time)
    raise Exception("Max retries exceeded")
