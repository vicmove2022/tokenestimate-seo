Understanding OpenAI Pricing

OpenAI charges per 1 million tokens. Input tokens are what you send, output tokens are what the model generates.

Key Points:

  • Input tokens: Your prompt + any uploaded files
  • Output tokens: The model's response
  • Reasoning tokens: o1 and o3 models use extra tokens for thinking
  • Total cost: Input + Output + Reasoning (if applicable)
