Tiktoken Python Tutorial

Learn to count tokens programmatically using Tiktoken in Python.

Aug 16, 2026 · 11 min read

Installation

pip install tiktoken

Basic Usage

import tiktoken

# Get encoding for a specific model
encoding = tiktoken.encoding_for_model("gpt-4o")

# Count tokens
text = "Hello, world!"
tokens = encoding.encode(text)
print(f"Tokens: {len(tokens)}")
print(f"Tokens: {tokens}")

Counting Tokens in Messages

def count_message_tokens(messages, model="gpt-4o"):
    encoding = tiktoken.encoding_for_model(model)
    
    num_tokens = 0
    for message in messages:
        num_tokens += 4  # Every message follows the format
    
    for msg in messages:
        num_tokens += len(encoding.encode(msg["content"]))
    
    return num_tokens

Cost Estimation Function

def estimate_cost(tokens, model="gpt-4o-mini"):
    pricing = {
        "gpt-4o-mini": {"input": 0.15, "output": 0.60},
        "gpt-4o": {"input": 2.50, "output": 10.00},
        "claude-3-haiku": {"input": 0.80, "output": 4.00}
    }
    
    prices = pricing.get(model, {"input": 0.15, "output": 0.60})
    input_cost = tokens * 0.7 * prices["input"] / 1_000_000
    output_cost = tokens * 0.3 * prices["output"] / 1_000_000
    
    return input_cost + output_cost

Handling Different Languages

# English text
encoding = tiktoken.encoding_for_model("gpt-4")
tokens_en = encoding.encode("Hello world")

# Chinese text (same encoding works)
tokens_cn = encoding.encode("你好世界")

# Note: Chinese characters may be encoded differently
# Consider using model-specific encoders for best results

Performance Tips

  • Cache encoders - creating encoding is expensive
  • Use batch processing for large documents
  • Consider approximate counting for very long texts
  • Use decode() to verify token integrity
