Tiktoken Python Tutorial

Learn how to use tiktoken in Python to count tokens for OpenAI models. Complete with code examples.

Aug 16, 2026 · 10 min read

Installation

pip install tiktoken

Basic Usage

import tiktoken

# Get encoder for specific model
enc = tiktoken.encoding_for_model("gpt-4o")

# Encode text to tokens
tokens = enc.encode("Hello, world!")
print(f"Tokens: {len(tokens)}")
print(f"Tokens: {tokens}")

# Decode tokens back to text
text = enc.decode(tokens)
print(f"Text: {text}")

Cost Estimation

def estimate_cost(text, model):
    enc = tiktoken.encoding_for_model(model)
    tokens = len(enc.encode(text))
    
    # Pricing per 1M tokens
    prices = {
        "gpt-4o": {"input": 2.50, "output": 10.00},
        "gpt-4o-mini": {"input": 0.15, "output": 0.60},
    }
    
    cost = tokens * prices[model]["input"] / 1_000_000
    return cost

print(f"Cost: ${estimate_cost('Hello world', 'gpt-4o'):.6f}")

BATCH Processing

texts = ["First text", "Second text", "Third text"]
results = [len(enc.encode(t)) for t in texts]
print(results)  # [5, 4, 4]

Common Errors

  • Model not found: Check model name spelling
  • Encoding errors: Ensure valid UTF-8 text
  • Memory issues: Process large texts in chunks
