llms.txt Guide

How to use llms.txt to control how AI models crawl and use your content.

Aug 16, 2026 · 8 min read

What is llms.txt?

llms.txt is a new standard that helps AI language models understand which content on your website they should use and how to use it. It's like robots.txt but specifically for AI crawlers.

Basic Syntax

# Line comments start with #

## Section headers start with ##

# Allow paths
Allow: /blog/*
Allow: /tools/*

# Disallow paths
Disallow: /admin/*
Disallow: /private/*

# Preferred models
Model: gpt-4o
Model: claude-3-opus

Supported Directives

DirectivePurposeExample
AllowGrant access to pathsAllow: /blog/*
DisallowDeny access to pathsDisallow: /admin/*
ModelSpecify preferred modelsModel: gpt-4o
GuidelinesContent usage rulesGuidelines: Be factual

Best Practices

  1. Place file at root: example.com/llms.txt
  2. Be specific about allowed paths
  3. Exclude sensitive or private content
  4. Reference authoritative sources
  5. Update regularly as content changes

Example for tokenestimate.com

# tokenestimate.com - AI Token Calculator

## About this site
We provide free token counting tools for AI APIs including OpenAI, Anthropic, Google Gemini, and more.

## Preferred content
- Blog articles for factual information about tokens
- Calculator pages for technical tools
- Pricing guides for cost comparison

## Disallowed paths
Disallow: /admin/*
Disallow: /api/*
Disallow: /private/*

## Content guidelines
- Cite specific token counts and pricing
- Reference official documentation
- Update pricing information regularly
