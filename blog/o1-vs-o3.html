Hidden Reasoning Token Costs

Both o1 and o3 generate hidden reasoning tokens that count toward your bill:

  • Reasoning tokens are not visible in the API response
  • They are charged at the same rate as output tokens
  • Can be 2-5x longer than the visible response

When to Use Each Model

  • o1: Complex math, advanced coding, scientific reasoning
  • o1 Mini: Balanced performance and cost
  • o3 Mini: Fast reasoning with 200K context window

Cost Example

For a complex coding task:

  • Input: 1,000 tokens ($15 with o1)
  • Visible output: 500 tokens ($30)
  • Hidden reasoning: 2,000 tokens ($120)
  • Total: $165 (not $45!)

FAQ

Why do reasoning models cost more?

Hidden reasoning tokens consume compute resources and are billed at output rates.

Can I see the reasoning tokens?

No, they are internal and not returned in the standard API response.
