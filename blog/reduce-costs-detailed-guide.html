How to Count Tokens for AI Models

A complete guide to understanding and counting tokens for GPT-4o, Claude, Gemini, and other AI models in 2026.

Aug 16, 2026 · 12 min read

What Are Tokens?

Tokens are the basic units of text that AI models process. One token can be as short as a single character or as long as a whole word. Understanding tokens is crucial for estimating API costs and optimizing your prompts.

How Tokenization Works

Different AI providers use different tokenizers:

  • OpenAI: Uses tiktoken with byte-pair encoding (BPE)
  • Anthropic: Uses CLAUDE_TOKENIZER (proprietary)
  • Google: Uses tokenizer based on sentencepiece

Counting Tokens for GPT-4o

To count tokens for GPT-4o and other OpenAI models:

import tiktoken

enc = tiktoken.get_encoding("o200k_base")
tokens = enc.encode("Your text here")
print(f"Tokens: {len(tokens)}")

Estimating Tokens for Other Models

For models without browser-accessible tokenizers, use this rule of thumb:

  • English text: ~4 characters per token
  • Code: ~3 characters per token
  • Chinese/Japanese: ~1-2 characters per token

Common Mistakes to Avoid

  1. Using character count instead of token count
  2. Not accounting for system prompts
  3. Ignoring output token costs
