What Are ChatGPT Tokens?

ChatGPT uses tokens as its basic unit of text processing. One token can be a word, part of a word, or even a single character.

Token Counting Methods

  • Exact: Uses tiktoken for OpenAI models
  • Estimate: ~4 characters per token for other models

ChatGPT Plus vs API

ChatGPT Plus subscription gives you access to GPT-4o with monthly token limits. The API charges per token used.
