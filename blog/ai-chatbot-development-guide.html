Simple Chatbot Implementation

from openai import OpenAI

client = OpenAI()

def chatbot_response(user_message, conversation_history=[]):
    messages = [
        {"role": "system", "content": "You are a helpful customer support assistant."},
        *conversation_history,
        {"role": "user", "content": user_message}
    ]
    
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        max_tokens=200
    )
    return response.choices[0].message.content

Cost-Optimized Architecture

  1. Intent classification: Route simple queries to cheap models
  2. Conversation summarization: Reduce context window usage
  3. Response caching: Store common answers
  4. Streaming output: Better UX with immediate feedback
