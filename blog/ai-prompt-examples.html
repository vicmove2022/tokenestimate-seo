Content Creation Prompts

Blog Post Writer

You are a professional blogger. Write a {word_count}-word article about {topic}.
Include:
- Catchy headline
- Introduction with hook
- {num_sections} main sections
- Conclusion with CTA
Target audience: {audience}

Email Template

Write a professional email to {recipient} about {subject}.
Tone: {tone}
Key points:
- {point1}
- {point2}
Keep it concise.

Social Media Post

Create a {platform} post about {topic}.
Requirements:
- Hook in first line
- Value proposition
- Call-to-action
- Relevant hashtags
Max {char_limit} characters.

Coding Prompts

Code Review

Review this code for:
1. Security vulnerabilities
2. Performance issues
3. Code style improvements
4. Bug detection

Code:
{code}

Provide specific fixes.

Generate Unit Tests

Write unit tests for this function:
{code}

Include:
- Normal cases
- Edge cases
- Error handling

Debug Assistant

Help me debug this error:
{error_message}

Code context:
{code}

Suggest possible causes and fixes.

Business Prompts

SWOT Analysis

Perform a SWOT analysis for {company/product}.
Consider:
- Market position
- Competitors
- Industry trends
- Customer needs

Business Plan Summary

Summarize this business plan in {num_words} words:
{business_plan}

Focus on:
- Value proposition
- Target market
- Revenue model

Learning Prompts

Explain Like I'm 5

Explain {complex_topic} as if I'm 5 years old.
Use simple analogies and avoid jargon.

Study Guide

Create a study guide for {subject}.
Include:
- Key concepts
- Practice questions
- Summary notes
